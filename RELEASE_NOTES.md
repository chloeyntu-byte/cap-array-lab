# Cap Array Lab v1.0.0

This initial public release includes Cap Array Lab and its bundled Z11 Studio. Runtime outputs, private workbooks, historical backups and site configuration are excluded. Native tool locations and workspace identities are user-configured.

The interface uses the shared RF-FIELDWORK cap theme: cyan primary actions, shared window headers, state chips and progress feedback, dark C/Q and impedance plots, and an empty-state example action. White Canvas plot backgrounds remain an explicit view option. Existing workbook formats and numerical algorithms are retained; Z11 annotations and small standard-library compatibility details were adapted for Python 3.6.

Start with `python3 app.py --project examples/ideal_array.json`. The two-page workbook and synthetic S2P are reproducibly generated by `python3 -m caplab.demo`. Example runs are clearly labeled synthetic replay and do not launch native tools.

Validation: 128 original tests passed before changes. The release adds analytic, Touchstone, UI/replay/stop, launcher and Z11 checks. Screenshots in `docs/screenshots/` show the real application on a private display. Core UI tests run under Python 3.6; Z11 GUI was exercised with an existing modern interpreter. See [docs/VALIDATION.md](docs/VALIDATION.md) for commands and evidence limits.

No licensed native simulation or live Maestro menu session was used. Native workflows require the user's installed tools, models and licenses. Module losses are unavailable in the synthetic example. This tool does not provide signoff verification.
